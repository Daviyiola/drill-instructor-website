# DIRI calibration files

## Authoritative launch implementation

- `../../functions/handlers/_diri.js` is the production DIRI 3.2 formula.
- `DIRI_V3_2_PROPOSAL.md` documents the launch calculation, evidence gates,
  confidence behavior, and interpretation. The historical filename is retained
  so existing references do not break; its contents describe the final formula.
- `diri-3.2-launch-stress-results.json` contains the deterministic launch stress
  grid generated by `runDiriLaunchStress.js`.
- `../../functions/test/diri.test.js` contains the production invariants and
  guardrail tests.

## Archived reference

- `diriV31Reference.js` is the frozen, executable DIRI 3.1 calculation. It is
  retained only for research and is not used by production analytics.

## Exploratory material

The notebook, HTML report, CSV/JSON simulations, and `runDiriV32Design.js`
capture earlier calibration work. They are useful for reconstructing decisions,
but they are not authoritative and must not be imported by production code.
